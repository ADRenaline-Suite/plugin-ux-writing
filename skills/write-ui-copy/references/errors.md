The message says invalid, or it blames the person, or it only turns the border red.

## Steps

1. Say what is wrong and how to fix it. Do not repeat an example that is already on the screen.
2. Do not use please, sorry, invalid, illegal, or oops.
3. Keep the value the person typed. A problem the person cannot fix by editing (no permission, no capacity) is not this component; say so and point at the page pattern instead of forcing a field error.

1. Do not invent a format the product did not specify.
