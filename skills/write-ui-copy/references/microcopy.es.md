## Pasos

1. Una clave. El botón empieza con un verbo. La etiqueta nombra el campo, no el tipo.
2. Si el producto nombró idiomas, escribe una entrada por idioma bajo esa clave. No añadas un idioma.
3. Las cadenas de vacío, carga y éxito se incluyen cuando la pantalla tiene esos estados. Las palabras salen de la tarea, no de una frase de stock.

## Reglas

1. No escribas un eslogan.
