El mensaje dice inválido, o culpa a la persona, o solo pone el borde rojo.

## Pasos

1. Di qué está mal y cómo corregirlo. No repitas un ejemplo que ya está en la pantalla.
2. No uses por favor, perdón, inválido, ilegal ni uy.
3. Conserva el valor que la persona escribió. Un problema que no se corrige editando (sin permiso, sin capacidad) no es este componente; dilo y señala el patrón de página en lugar de forzar un error de campo.
